## 📖 عن المشروع

دليل تفاعلي لمساعدة طلاب جامعة المأمون في معرفة الأقسام المتاحة بناءً على معدلاتهم وفرعهم الدراسي، مع عرض الأقساط الدراسية وحالة القبول (صباحي/مسائي).

### ✨ المميزات
- 🔍 **بحث فوري** بالاسم أو الكلية
- 📊 **تصفية متقدمة** حسب الفرع والتخصص الدقيق
- 💰 **عرض الأقساط** الدراسية بشكل واضح
- ✅ **حالة القبول** (مؤهل / غير مؤهل / غير منشور)
- 📋 **نسخ معلومات القسم** بنقرة واحدة
- 📱 **تصميم متجاوب** مع جميع الأجهزة

## 📊 البيانات

تعتمد الأداة على البيانات الرسمية الصادرة عن جامعة المأمون للعام الدراسي 2026-2027، وتشمل:
- 12 كلية
- 42 قسماً أكاديمياً
- المعدلات الدنيا للقبول (صباحي ومسائي)
- الأقساط الدراسية المحدثة
