# دليل الطالب — جامعة المأمون

موقع استعلام مستقل (بدون تسجيل دخول أو بوابات إدارة) لعرض الأقسام والأقساط الدراسية بناءً على ملف **"الأجور الدراسية"** الرسمي.

## المحتوى
- `index.html` — الملف الوحيد المطلوب، جاهز للعمل مباشرة بمجرد فتحه أو رفعه.

## البيانات
- **45 قسماً** موزعة على **17 كلية**، مستخرجة برمجياً (خلية بخلية عبر pandas) من ملف الإكسل المرفق مباشرة — وليس بالقراءة البصرية أو OCR، لضمان الدقة الكاملة.
- كل قسم يعرض: القسط الداخلي، الحد الأدنى للقبول صباحي/مسائي، والمدخلات المقبولة (الفروع والقنوات).
- تم تصحيح أخطاء إملائية واضحة في المصدر الأصلي فقط (مثل "الحياني" ← "أحيائي"، "تقنيات العلم والانجاب" ← "تقنيات العقم والإنجاب"، "هندسة الطلب الحياتي" ← "هندسة الطب الحياتي") دون تغيير أي رقم.
- الأقسام المدمجة في المصدر بصف واحد (مثل "علوم الحياة / علوم التحليلات المرضية") تم فصلها إلى بطاقتين منفصلتين بنفس القيم لسهولة البحث.

## طريقة الرفع على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع `index.html` إلى جذر المستودع.
3. من **Settings → Pages**: اختر الفرع `main` والمجلد `/root`، ثم احفظ.
4. سيصبح الموقع متاحاً على: `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`

## ملاحظة
لا يحتوي هذا الملف على أي بوابة دخول للداعمين أو لوحة إدارة — فقط دليل استعلام عام للطلاب بالبحث بالاسم أو المعدل.
